These glyphs are drawn — each one is constructed from geometric primitives on a shared 100×100 grid with a single stroke weight, so the set reads as one coherent script rather than traced handwriting. They are clean interpretations of the reference key, not facsimiles of it. Eight sounds have no symbol anywhere in the reference material yet and show as a dashed "?" box throughout the tool.

Each cell below shows the drawn glyph the tool renders next to the shape traced straight out of the hand-lettered key, so the two can be compared. Where a cell is missing one side, that sound is drawn without a source, or sits in the key without a home in the set.
