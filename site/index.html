How to write sounds

Each sound is written as a short code, sounds separated by spaces and words by /. Click any glyph in the reference to add its code here.

K AH T AA R AH spells Katara. The codes are the ones used in pronunciation dictionaries; real IPA works too if you prefer it (k ə t ɑ r ə).

Anything in (brackets) is a label for that word, not a sound — that is how the English caption under each word gets there.

0 fills an empty slot at the end of a word with an odd number of sounds. Adding $ or % after a sound forces its top or bottom form, which is only needed for S, where the rule still isn't known.
