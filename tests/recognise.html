Recogniser accuracy

The one part of the suite that cannot run in node: recognise.js samples its reference shapes with getPointAtLength, which is browser geometry. So this page is the test.

Each glyph's own outline is traced back through the matcher at a random scale and offset, under four kinds of degradation, and we check it still recognises itself. Floors are set below the numbers measured when the recogniser was written — they are there to catch a scoring change that quietly makes things worse, not to police the exact figure.

Open this from the dev server (python3 -m http.server 8791 --directory site then /../tests/recognise.html), or just open the file — it loads the site's scripts by relative path and needs no server.
