How this works

Draw the shape freehand and it gets tidied up. Every character sits on the script's own lattice — 5×5 for a consonant, 5×4 for a vowel, the two stacking flush in a block — and a brushed stroke is read against it: corners land on lattice points, runs that were meant to be straight come out straight, and curves come out as real circular arcs.

Drawing

  • brush — draw the whole shape in one drag. Wobble doesn't matter; what's read off it is where you turned, where you went straight, and how hard you curved. Finish near where you started and the shape closes itself. A small scribble becomes a dot.
  • tidy — how hard to regularise. close keeps more of the gesture, clean forces it harder onto the lattice. Changing it re-reads the selected stroke straight away, so you can see the difference rather than guess it.
  • re-read (R) — run the gesture through again. Every brushed stroke keeps the raw gesture, so this always re-reads what you actually drew; it never compounds one fit on top of another.
  • Draw one stroke at a time. Three separate strokes make three shapes, which is what you want for something like /h/ or /z/.
  • use it, by the current glyph underlay — starts you from the glyph the set already ships instead of a blank lattice. It samples that drawing back into a gesture and runs it through the same fitter, so what lands is a proper lattice design you can nudge, not a copy of the old path's coordinates.

When the fit reads something wrong

Switch to select and drag a node — the fitted result is an ordinary path, so everything is adjustable. Drag a segment's mid-handle sideways to bow it, back onto the chord to straighten it. The by hand tray has node-by-node drawing and the segment types if you want them, but you shouldn't need it often.

Starting from another letter

paste in…, by the output tabs, takes back any of the three things the panel hands out — a design JSON, an SVG, or a build_glyphs.py entry. Copy a letter that's nearly what you want, open the one you're drawing, paste, adjust. The or copy from dropdown fills the box straight from another glyph's design, and anything quoted at you elsewhere can go in the same way. The ↔ and ↕ toggles mirror the incoming shape left–right or top–bottom — the fastest way to start from a mirror pair (e.g. /ə/ → /ɜ/).

The ⇄ and ⇅ buttons in the toolbar (or ⇧H / ⇧V) mirror what you've already drawn, in place. Undoable.

A design JSON is already lattice data, so it comes in untouched. An SVG or a Python entry is drawing coordinates, so it gets sampled and fitted the same way a brush stroke does. Nothing is rescaled to fit a different grid — a consonant shape on a vowel's shorter lattice hangs over the bottom and gets flagged, which is easier to fix than a silent squash.

Where it goes

Each glyph saves to designs/<name>.json as you draw. The for build_glyphs.py tab is the handoff — that snippet is rendered by the Python, not by the browser, so it is exactly what the build will draw.
